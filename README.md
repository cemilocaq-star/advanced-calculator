# Uncensored AI Girls

Adults-only (18+) AI companion & roleplay chat. React + Vite + Tailwind frontend, Supabase backend
(Postgres + Edge Functions), replies generated by Claude (Anthropic API).

## What's new in this version
- **Real bug fixes** – the original zip had a broken Supabase import, a missing `types`, a missing `admin-api`
  client, and `CreateCharacterModal` was a copy of `ChatView`. All rebuilt.
- **Streaming replies** with a Stop button, **Regenerate**, **Clear chat**, `*action*` italics.
- **Favorites** (heart on a card), resume existing chat instead of creating duplicates, new categories.
- **8 starter characters** (all fictional adults) so Discover isn't empty.
- **Create-character form** with name, age (18+), tags, category, avatar URL, greeting, scenario…
- **18+ age gate** on first visit.
- **Security**: per-visitor anonymous accounts + strict Row Level Security (the old policies let anyone read/delete
  every chat and read every admin token), `chat_count` maintained by a DB trigger, hashed admin session tokens,
  no default admin password, login throttling, per-user rate limit and input limits on the chat function.
- **Safety rails**: every character must be 18+ (DB constraint + server check + UI check); keyword/age filter on
  character text; the system prompt keeps adult-only limits, answers honestly if sincerely asked "are you an AI?",
  and steps out of character if the user seems to be a minor or in distress.

## Update 2 – more characters, photos, admin publishing
- **47 official characters** across 8 categories (Original, Anime, Fantasy, Sci-Fi, Romance, Roleplay,
  **Mythology**, **Classics**). "Existing" characters are public-domain / traditional figures only: Greek, Norse,
  Celtic and Japanese myth (Aphrodite, Persephone, Circe, Freya, Kuzunoha…) and literary classics (Carmilla,
  Scheherazade, Irene Adler, Titania, Morgan le Fay…). Real living people and franchise-owned characters are
  intentionally not included.
- **Character pictures**: each official character has a hand-built illustrated avatar (`public/avatars/*.svg`,
  generated by `src/lib/avatar.ts`). New user-created characters get an auto-generated avatar if no image is given.
- **Admin → "Add character" tab**: fill the form, upload a photo (PNG/JPEG/WEBP/GIF, max 2 MB, stored in the public
  `avatars` bucket) or generate an avatar, and press **Publish for all users**. The character is marked *Official* and
  appears **instantly for every visitor** (Supabase Realtime, 60 s polling fallback, plus a toast "New character: …").
  In the admin Characters list you can also change a character's photo.
- Discover page: **Official** filter, **Just added** row, **NEW** and ✔ Official badges.
- Regenerate seeds/avatars after editing `scripts/seed-characters.mjs`: `npm run seed:build`
  (rewrites `public/avatars` and the `…official_characters_admin_realtime.sql` migration).

## Update 3 – AI admin assistant, heat levels, live app settings, Android APK
- **Admin → "AI" tab**: chat with an assistant (Claude with tools) that can design a character from a description
  (every field + the look + heat level), edit *any* detail of existing characters, delete characters, and change app
  settings. It always shows a **draft card first**; nothing reaches users until you press **Publish** (or "Edit first").
  Published characters/settings appear for **all users instantly** (Supabase Realtime).
- **Heat level 1–5** per character (Sweet → Flirty → Romantic & sensual → Steamy → Spicy). Users can pick a level per chat
  (header "Heat" dropdown) up to a **global cap** the admin sets. The chat model keeps its own judgment about graphic
  detail at every level, so level 5 means "as forward as the model will go", not "unfiltered".
- **Admin → "App settings"**: app name, tagline, accent/gradient colours, announcement banner, show/hide sections,
  allow user-created characters, maintenance mode, global heat cap, max reply length (200–8000 tokens), chat model and a
  private global style prompt. **Undo last publish** restores the previous version.
- **Tokens**: there is no such thing as unlimited tokens (the provider bills per token). The admin assistant gets up to 16 000
  output tokens per step, auto-continues when cut off and runs up to 12 tool steps per message; chat replies are
  configurable up to 8 000 tokens.
- **Android APK** via GitHub Actions (see below). In the app, tap the logo **7 times** to open the admin panel (no keyboard needed).

### Update 4 – heat level 6 and a smarter chat AI
- **Heat level 6 ("Maximum")**: the platform adds no softening at this level (no fade-to-black, hedging, disclaimers or
  lectures). It is **opt-in**: set *App settings → Max heat level* to 6 (or ask the AI tab to), then pick 6 per character or per chat.
  What it does **not** do: it cannot remove the model's own safety judgment or the hard limits (adults only, no minors, no real
  people, step out of character if the user seems unwell or sincerely asks if she is an AI). Those stay at every level.
- **Long-term memory**: long chats are summarised in the background (small fast model) into a running memory that is
  fed back to the character, so she keeps remembering names, promises and shared events beyond the last 30 messages.
- **"About you"** (person icon in the chat header): your name and notes for that chat, plus a view of what she remembers
  with a "Make her forget this" button.
- **Example dialogue** per character (admin form and AI tab): a short sample of how she talks, the strongest lever for a
  consistent voice. The AI assistant now writes one for every new character and can add them to existing ones.
- Better prompt craft (no speaking for the user, less repetition, scene always moves forward, matches message length) and
  prompt caching for the stable persona part to cut cost and latency.
- New migration: `20261019100000_level6_memory_profile.sql`. Re-deploy `chat-completion` and `admin-ai`.

### Build the APK on GitHub
1. Push this folder to a GitHub repo.
2. Repo → **Settings → Secrets and variables → Actions → New repository secret**:
   `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` (required).
   Optional, for a signed *release* APK: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.
3. **Actions → Build Android APK → Run workflow** (or push a tag like `v1.0.0` to also create a GitHub Release).
4. Download the artifact **UncensoredAIGirls-apk**, unzip it and install `UncensoredAIGirls-debug.apk` on your phone
   (allow "install unknown apps"). The debug APK is fully usable; the signed release APK is only needed for stores/updates.
- What updates **without** reinstalling: characters, photos, theme colours, texts, banner, toggles, heat/token limits, model, prompts.
  Changes to the app's *code/layout* need a new APK build (run the workflow again).

## Setup
```bash
npm install
cp .env.example .env        # fill VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY
npm run dev
```

### Supabase
1. Run the SQL files in `supabase/migrations/` in order (or `supabase db push`). The newest one adds the official
   characters, the `avatars` storage bucket and enables Realtime on `characters`.
   The last one upgrades an existing database. Chats created under the old open policies have no owner and
   will no longer be visible – that is intentional.
2. Dashboard → **Authentication → Sign In / Providers → enable "Anonymous sign-ins"** (required).
3. Set secrets and deploy the functions:
```bash
supabase secrets set ANTHROPIC_API_KEY=sk-ant-...
supabase secrets set ADMIN_PASSWORD='a-long-random-password'
supabase secrets set ALLOWED_ORIGIN=https://your-domain.com     # optional but recommended
supabase secrets set ANTHROPIC_MODEL=claude-sonnet-5-5          # optional (default)
supabase functions deploy chat-completion
supabase functions deploy admin-api    # character CRUD, upload, app settings
supabase functions deploy admin-ai     # the AI assistant (new)
supabase functions deploy chat-completion   # re-deploy: heat levels + settings
# optional: supabase secrets set ANTHROPIC_ADMIN_MODEL=claude-opus-5-5
```
4. Admin panel: type `admin` anywhere on the page (not inside an input) and log in with `ADMIN_PASSWORD`.
   If `ADMIN_PASSWORD` is not set, admin login is disabled.

## Notes before going public
- The age gate is a self-declaration. Depending on where you operate, adult platforms may legally need real age
  verification and content moderation – check local law and your payment/hosting providers' policies.
- Anthropic's usage policy applies to everything sent to the API; the app never routes around the model's own
  judgment, so some requests will be declined or steered away by design.
- Ideas for next steps: user accounts (email login), character reports/moderation queue, image avatars via
  Supabase Storage, message edit, long-term memory summaries, i18n (Turkish/English toggle).
